# Content guidelines

事实精确、叙述克制。保留日文艺名与已确认假名，中文译名是本站索引标签，并非声称本人认可的官方译名；英文遵从本人或事务所罗马字并补充搜索词序。

姓名、生日、所属、出演、获奖、发行日期都能回到证据。来源对象保存抓取日期、类型和置信度；日期表示本轮查阅，并不表示事实从那一天开始。重要事实在人物页的来源 details 中按字段映射。

不写年龄猜测、私人住址、联系方式、传闻、情感经历、粉丝刻板印象。没有依据不写“最受欢迎”“天才”“声线治愈”等事实式判断。原创专题清楚署为编辑札记，不伪装采访、名言或本人观点。

空字段不显示。没有年份只显示 MM.DD，不借百科补全年份然后冒充官方核验。出道必须限定为声优出道，音乐出道另列活动；无法确认则搜索条件下归入未记载。

更新流程：查官网 → 记录事实和 source ID → 交叉核验 → 标注冲突 → 运行内容验证 → 预览相关人物 / 关系页面。演出清单是精选，不表示完整履历。失效来源保留原 URL 和状态，不能改造成伪造官方 URL。
