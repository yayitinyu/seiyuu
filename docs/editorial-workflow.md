# 编辑工作流

## 内容与版本

`content/archive.json` 是公开内容的唯一事实来源，Git 提交是长期版本记录。本地 `npm run studio` 提供单人文件编辑台，绑定 `127.0.0.1:3210` 并使用每次启动生成的令牌。它不具备多人身份认证，不应通过反向代理或端口转发开放给他人。

编辑台可选择来源、人物、作品、角色、事务所和媒体记录，或编辑整份 JSON。保存会检查字段证据、引用关系、授权记录及媒体原件；若文件已被其他进程修改，返回冲突而不覆盖。旧档案保存在 `content/.revisions/`，该目录不进入 Git。保存后运行 `npm test`、`npm run typecheck`、`npm run build`，并预览受影响的三语页面。

## 来源版本

运行 `npm run audit:sources` 检查全部来源，或在命令后列出来源 ID 只检查指定条目。脚本并发最多 3 个请求，单页 12 秒超时、2 MB 上限；结果写入 `content/source-audit.json`。记录 URL、检查时间、HTTP 状态、最终 URL、响应字节数和 SHA-256，不保存网页正文或受版权保护的图片。相同响应不重复生成版本。站点动态内容可能造成与事实无关的指纹变化，因此必须人工对照相关字段。

编辑台的“版本记录”列出每次不同的观察。打开官网，确认与 `evidence`、角色或作品记录有关的内容后，由实际审核人填写姓名及审核说明。带成功指纹的审核绑定该 SHA-256；下次指纹或来源 URL 变化会变为 `changed`。网页返回 403、超时或连接失败时，可记录人工核验，但状态为 `manual`，不能声称版本已自动比对；30 天后恢复 `unavailable`。HTTP 成功只说明页面可读取，不证明事实正确或获得转载许可。

来源的 `retrieved_at` 表示事实查阅日期，自动检查不会改写它，也不会自动修改 `verified` 或置信度。来源失效时保留原 URL；若官网事实互相冲突，在 `conflicts` 中记录各自断言与来源，由编辑人工裁决，不以来源优先级自动覆盖。

## 三语人工审校

`content/locale-reviews.json` 初始为空。实际具备相应语言能力的人需阅读中文、日文、英文页面，核对姓名、译名、说明、角色、导航与站内文案，然后在编辑台分别记录审核人和说明。审核摘要覆盖档案、UI 字典和编辑札记；任何共享内容变化都会使三语记录全部变为 `stale`。摘要是变更检测，不是语言质量证明。

`npm run editorial:status` 显示待审情况。发布前运行 `npm run editorial:gate`；三语未全部签署、来源仍有 `pending` / `changed` / `unavailable` / `not-checked` 时返回非零。人工核验状态仅在 30 天内满足闸门。当前首次来源检查尚待真人复核，闸门预期不通过。此闸门为本地发布步骤，GitHub 镜像工作流目前不自动执行它。

## 授权素材

只有取得本站明确使用许可后，才将原件放在 `content/media/` 并在档案 `media` 数组建档。`authorizationRef` 是仓库外授权证明的索引，不是合同正文。肖像需 `portrait-display` 用途、三语 alt、真实尺寸和明确的裁剪许可；无裁剪许可时按原图比例完整呈现。音频需 `audio-stream` 用途。两者都要记录权利人、许可开始日、到期日或明确的永久授权、全球使用范围、审核人及日期、真实文件 SHA-256、格式和署名要求。当前服务不具备按访问者地区限制播放的能力，因此不能接入地区受限授权。

`imageStatus: LICENSED` 只在人物指向通过校验的肖像时使用；否则保留 `IMAGE_LICENSE_TODO` 及文字封面。未经授权的官网声音页面仍只作为外链。许可到期后 `/media/[id]` 会拒绝提供文件；到期或撤权时应立即移除关联、重新构建，并清理已发布的缓存。浏览器已接收的副本无法技术性撤回，因此授权范围需覆盖公开提供所带来的缓存风险。
