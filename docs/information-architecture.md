# Information architecture

- `/` → `/zh-CN`；`/seiyuu` 与 `/seiyuu/:slug` 提供中文兼容跳转。
- `/{zh-CN|ja-JP|en}`：首页，选辑 → 声优与角色关系 → 札记 → 当月生日。
- `/{locale}/seiyuu`：搜索、事务所 / 生日月 / 性别（有来源）/ 出道年 / 年代、五十音；URL 保留筛选，可分享 / 返回。
- `/{locale}/seiyuu/:slug`：人物头部 → 人物介绍 → 角色与作品 → 时间轴 → 音乐 / 广播 / 舞台等延伸 → 链接 → 可展开的来源记录。无证据的板块不造空记录。
- `/{locale}/works/:slug`：原名、媒介、已验证出演、回到人物与官方作品页。年份未知时不填充。
- `/{locale}/journal`：原创编辑札记，完整阅读而非假链接。
- `/{locale}/about`：项目定位、编辑与图像政策、覆盖边界。
- 全局搜索：人物 / 角色 / 作品 / 事务所；角色跳到人物角色锚点、作品进作品页、事务所进带筛选的目录。

LanguageSwitcher 保留当前页面；检索不依赖界面语言。桌面和手机同一内容，布局不同。Voice Graph、账户、CMS、新闻抓取放到后续阶段。
