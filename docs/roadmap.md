# Roadmap

1. Research：官方、聚合库、设计与技术资料，记录不可访问的研究边界。
2. Brand：纸本、墨、声音线谱；生成视觉概念及原创录音室图。
3. IA：三语目录与人物—角色—作品路径。
4. Design system：tokens、type、响应式、可访问性。
5. 首页原型：先完成首屏与选辑，在浏览器观察。
6. 早見沙織人物页：来源、角色、时间轴和延伸内容；验证视觉语言。
7. 扩展 8 人：同一模板 + 实际搜索 / 筛选 + 作品关系。
8. 响应式：1440、1280、768、390，检查导航、封面、目录、时间轴。
9. Motion：CSS 细节与 reduced-motion，禁止滚动劫持。
10. SEO / Performance / A11y：预渲染、metadata、JSON-LD、sitemap、robots、OG、键盘、自动检测。
11. 内容复核：引用外键、日期精度、关系、来源和图片状态校验。
12. Polish：概念对照、完整路径回归、说明实测与待验证范围。

Phase 2：授权肖像与声音播放、编辑 CMS、PostgreSQL、来源版本与冲突审核、Voice Graph、更多人物、正式多语言审校。授权和数据不足时不以虚构素材填补。不自动部署或购买域名。
