# Seiyuu / 声優

这个网站为什么值得存在？**让人们从记住一个角色，走向认识赋予它声音的人，并能追溯每一个事实。**

不是以资料数量取胜的百科，而是一座可阅读、可探索、可核验的声音人物档案馆。中文是第一阅读语言，日文保留姓名和作品的原始语境，英文让档案可以被更广泛地发现。

品牌主句：声を知る。人を知る。中文叙事：每一个被记住的角色背后，都有一个值得认识的人。英文标识：A living archive of Japanese voices.

以编辑选择代替热度榜，以人物—角色—作品关系代替孤立卡片，以来源记录代替权威语气。核心路径是首页 → 人物 → 角色 / 作品 → 共演者；搜索让知道名字的人直接抵达。

首版是八人的精选档案，不声称完整覆盖行业。首页、早见沙织人物页先成立，再扩展同一套内容模板。未核实的出生年、出道年、性别和角色主配分类留空。没有授权的照片不使用。

设计成功的证据：第一屏有辨识度；390px 上阅读舒适；键盘可以完成搜索；每条事实有出处；没有阻碍阅读的动画。设计奖是追求方向，不是自我授予的评价。
